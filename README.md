# 🚌 Smart Bus Tracking System

A full-stack real-time bus tracking web application with AI features.

## 🌟 Features

- 📍 Live GPS Tracking (Real-time)
- 🤖 AI Chatbot (Google Gemini)
- 🎤 Voice Search
- 👨‍💼 Admin Dashboard (Bus/Route/Driver Management)
- 🚌 Driver Dashboard (Live Location Sharing)
- 👤 Passenger Dashboard (Bus Search, ETA, Schedule)
- 🔒 Secure Login (Bcrypt + JWT)
- 📊 Bus History & Analytics
- 🌙 Dark Mode
- 📱 Mobile Responsive

## 🛠️ Tech Stack

- **Backend:** Python, Flask, Flask-SocketIO
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Real-time:** Socket.io
- **Maps:** Leaflet.js
- **AI:** Google Gemini API
- **Security:** Bcrypt, JWT, Rate Limiting

## ⚙️ Installation

```bash
pip install -r requirements.txt
python app.py
👥 User Roles
Admin - Manage buses, routes, drivers
Driver - Share live location, update passengers
Passenger - Track bus, search routes, get ETA
```
